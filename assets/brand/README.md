# Netmap — Brand assets

Netmap graphic resource package, available in vector SVG and PNG formats. The SVG files are standalone, ready for use and editing. The wordmark text remains as SVG text and uses the "Inter Display" font (with "Inter," "Lato," or "Arial" as fallbacks); if you wish to ensure it looks identical across all software, use the PNG files or convert the text into outlines/paths within your vector editing software.

## Folders
- `svg/`: logo, wordmark, payoff, icons and app icon in SVG.
- `png/`: PNG exports, with transparency where relevant.
- `favicon.ico`: multi-size favicon for websites.
- `PALETTE.txt`: recommended colours and fonts.
- `preview.png`: preview of the asset set.

## Main files
- `svg/logo-primary.svg` / `png/logo-primary.png`: horizontal logo, transparent background.
- `svg/logo-primary-dark.svg` / `png/logo-primary-dark.png`: logo on a dark navy background.
- `svg/app-icon.svg` / `png/app-icon.png`: app icon on a navy background.
- `svg/wordmark-color.svg`: coloured wordmark only.
- `svg/wordmark-with-payoff.svg`: wordmark with payoff.
- `svg/logo-monochrome-dark.svg` and `svg/logo-monochrome-light.svg`: monochrome variants.
- `svg/icon-only.svg` and `svg/icon-minimal.svg`: symbol on its own, normal and minimal variants.
- `svg/favicon.svg` and `favicon.ico`: web favicon.

To add the favicon to HTML: `<link rel="icon" href="/favicon.ico" sizes="any">`, or use `svg/favicon.svg` as an SVG icon.
